PromptForge

Agentic Prompt Support System
100% client-side · offline
1

Intake Agent

Normalizes your input, detects whether it's a conversation, transcript or idea, and extracts people, systems, actions, constraints, goals and questions with heuristic NLP.

2

Intent Agent

Scores the text against weighted keyword/phrase patterns to classify the underlying intention — task execution, support resolution, planning, and more — with confidence percentages.

3

Context Handler

Recommends one of four context levels (L1 Minimal → L4 Agent/System). Slide between levels and every generated prompt restructures live.

4

Structure Agent

Emits the same request as six prompt types in parallel: zero-shot, few-shot, chain-of-thought, role-based, JSON-output and an agentic tool-use spec.

5

Critic Agent

Scores each prompt on clarity, specificity, context completeness and constraint coverage, with a one-line suggestion for the weakest dimension.

✓

Private by design

No backend, no API keys, no network calls. All "agents" are deterministic client-side heuristics — your text never leaves this page.
